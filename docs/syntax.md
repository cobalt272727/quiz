# QB Markup 記法リファレンス(SPEC_v4 §4 準拠)

問題ブックは 1 ファイル = 1 ブックです。先頭に YAML フロントマターを置き、本文を Markdown 風の
記法(QB Markup)で書きます。**HTML は解釈しません**(安全のため HTML はテキストとして扱います)。

## 1. フロントマター

```yaml
---
title: 日本史 基礎          # 必須
description: 古代〜中世      # 任意
tags: [history, japan]
lang: ja                    # ja / en
timeLimit: 600              # 秒(任意)
practiceFeedback: true      # 練習モードの即時採点と正解表示を許可(既定 false)
shuffle: { questions: true, choices: true }
normalize: { kana: false }  # true でひらがな/カタカナを同一視
---
```

`tags` はブロック形式(`tags:` の下に `- a`)でも書けます。未知のキーはエラーになります。

## 2. ブロック要素

| 記法 | 意味 |
|------|------|
| `#` `##` `###` | 見出し(章・節) |
| 空行区切りの文 | 段落 |
| `**太字**` `*斜体*` `` `コード` `` | インライン装飾 |
| `[表示](https://…)` | リンク(スキームは `http` / `https` / `mailto` のみ) |
| `$x^2$` / `$$…$$` | 数式(KaTeX) |
| `![代替テキスト](img:name.png){width=400}` | 画像(ブック内アセット) |
| Markdown 表 | 表(セル内に空欄・書式・数式) |
| `- ` / `1. ` | リスト |
| `@text … @end` | 表示専用ブロック(記法は解釈、`[[…]]` は文字のまま、設問にしない) |
| ```` ``` ```` で囲んだ範囲 | コードブロック(中の記法は解釈しない) |

画像は既定で `img:`(ブック内アセット)のみ許可されます。外部 URL(`https://…`)はサイト設定で
許可した場合だけ使え、そのときは警告 `QB-W002` が出ます。

## 3. 空欄(採点対象)

| 記法 | 意味 |
|------|------|
| `[[答え]]` | 自由記述(完全一致) |
| `[[答え1 \| 答え2]]` | 許容解答(いずれかに一致すれば正解) |
| `[[/正規表現/]]` `[[/正規表現/i]]` | 正規表現(RE2 互換サブセット、`i` フラグのみ) |
| `[[=3.14]]` `[[=3.14 ±0.01]]` | 数値(許容誤差つき) |
| `[[?正解 \| 誤り]]` | 選択肢空欄(ドロップダウン) |

- 選択肢空欄: `?` を付けた選択肢がすべて正解です(複数可)。先頭の `?` を文字として使うときは `\?`。
  `?` が 1 つも付いていない式は自由記述空欄になります。
- 自由記述の比較では NFKC → 前後空白除去 → 英字大小無視 →(`normalize.kana` が true なら)かな同一視
  を行います。内部の連続空白は圧縮しません。
- 数値は全角数字、負号の異体字(`−` `－` `‐`)、3 桁区切りのカンマ(`1,234.5`)を受け付けます。
  `1,5` のような区切りは不正解です。`NaN` / `Infinity` / 単位付き(`10cm`)は不正解。
- 表のセル内では `|` の代わりに `\|` を区切りに使います。

### 配点

- `@q points=2` で設問の配点、`[[…]]{w=3}` で空欄の重みを指定できます(どちらも上限 1000)。
- `points` を省略(または `points=-1`)すると、設問内の空欄の重み `w` の合計が配点になります。
  空欄を持たない設問(選択・真偽・記述)は 1 点です。
- 複数空欄の設問は `points × (正解した空欄の重み合計 / 全空欄の重み合計)` を按分します。
- 設問得点は小数第 3 位を四捨五入して 2 桁で確定します(丸めは設問単位で 1 回)。

### 空欄の属性

```
[[答え]]{id=b_a1c9x2 w=2}
```

- `id`: 空欄 ID(省略時は保存時に自動付与してソースへ書き戻す)
- `w`: 重み(既定 1)

## 4. 設問ブロック `@q`

```
@q id=q_k3m9p1 points=2
聖徳太子が制定した憲法を答えよ。
[[十七条憲法 | 十七条の憲法]]
@explain
604 年に制定された。
@end
```

| 属性 | 値 |
|------|----|
| `type` | `blank`(既定) / `single` / `multi` / `essay` / `truefalse` |
| `points` | 正の数(上限 1000。省略時は空欄の重みの合計、空欄のない設問は 1) |
| `tags` | カンマ区切り |
| `scoring` | `all`(既定) / `partial`(`multi` のみ) |
| `answer` | `true` / `false`(`truefalse` で必須) |
| `id` | 設問 ID(省略時は自動付与) |

セクション指示子:`@explain`(解説)、`@hint`(ヒント)、`@model`(模範解答。`essay` 用)、`@end`(終端)。

### 選択肢(`single` / `multi`)

```
@q type=multi id=q_h4n8c3
次のうち室町時代のものをすべて選べ。
- [x] 勘合貿易
- [ ] 墾田永年私財法
- [x] 応仁の乱
@end
```

選択肢 ID は出現順に `c1`, `c2`, … と決まります。`multi` の部分点は `scoring=partial` で有効になり、
`max(0, 正しく選んだ数 − 誤って選んだ数) / 正解数 × points` で計算します。

### 真偽・記述

```
@q type=truefalse answer=false id=q_r2v6f8
冠位十二階は 604 年に制定された。
@end

@q type=essay points=5 id=q_essay01
飛鳥時代の政治改革を説明せよ。
@model
冠位十二階と十七条憲法によって…
@end
```

`essay` は提出後に模範解答が開示され、本人が ◯(満点)/△(半分)/✕(0 点)で自己採点します。

## 5. 表示専用ブロック `@text`

`@text … @end` は、採点しない文章を出すためのブロックです。エディタのプレビューだけでなく、
受験画面・結果画面でもそのまま表示されます。

```
@text
この文章は **太字** や $x^2$、[リンク](https://example.com) を解釈して表示します。
`[[答え]]` や `{id=...}` は空欄にせず、文字として表示します。
- リストや表、画像も書けます
@end
```

- 中の Markdown 記法(太字・リスト・表・数式・リンク・画像・コード)は解釈します。
- `[[…]]` は空欄にせず、文字として表示します。設問も生成しません。
- `@text` の中に `@q` は書けません(`QB-E010`)。
- コードブロック内の `@end` は `@text` の終端として扱いません。
- 出題順をシャッフルしても `@text` は書いた位置に残り、設問だけが入れ替わります。
- `@text` の外にある通常文・見出し・表などは、エディタのプレビューには表示されますが、
  受験画面・結果画面には表示されません。保存前の診断で `QB-W003` 警告を出します。

## 6. 設問にしない空欄(自動設問)

`@q` で囲まない空欄は、**段落・リスト項目・表の行ごとに 1 問**として自動生成されます
(1 つのブロックに空欄が複数あっても 1 問で、部分点になります)。表全体を 1 問にしたいときは
表を `@q … @end` で囲んでください。

自動生成された設問の ID は、保存時に `{qid=…}` としてソースへ書き戻されます。
段落・リスト項目は末尾、表の行は最終セルの末尾です。

```
聖徳太子は [[603]] 年に冠位十二階を制定した。 {qid=q_m2x7a4}
```

## 7. ID とバージョン

- 設問 ID は `q_`、空欄 ID は `b_` + 小文字英数字 6〜16 文字(`^[qb]_[a-z0-9]{6,16}$`)。
- ID はブック内で一意。並べ替え・移動では変わりません。削除した ID は再利用できません(退役 ID)。
- 未指定の ID は保存時に自動付与され、確定済みのソースが応答として返ります。
  **エディタは応答のソースで置き換えてください**(置き換えないと次の保存で ID が再採番されます)。
- 採点に影響する変更(正解・Matcher・選択肢・`scoring`・`points`・重み・`normalize`)は
  設問リビジョンを更新します。誤字修正などは更新しません。

## 8. エスケープ

| 記法 | 意味 |
|------|------|
| `\[[` | `[[` という文字列(空欄にしない) |
| `&vert;` | 解答文字列中の `\|` そのもの |
| `\|` | 表のセル内での空欄の区切り |

`[[` / `@q` / `@explain` などは、コードブロック・インラインコード・数式・リンクの URL と表示テキスト
の中では解釈しません。`@text` の中でも `[[` / `{id=...}` は文字として扱います。

## 9. 廃止された記法

`{{答え}}` は廃止されました。使用すると `QB-E006` になります。`[[答え]]` を使ってください。

## 10. 診断コード

| コード | 内容 |
|--------|------|
| QB-E001 | ID の重複 |
| QB-E002 | `[[` / `@q` が閉じていない |
| QB-E003 | 表内で未エスケープの `\|`(セル数の不一致) |
| QB-E004 | RE2 互換でない正規表現 / 長さ超過 |
| QB-E005 | 参照している画像が解決できない |
| QB-E006 | 廃止記法 `{{ }}` |
| QB-E007 | 配点 `points` / 重み `w` が範囲外 |
| QB-E008 | 設問の正解定義が不正 |
| QB-E009 | 数値空欄の構文不正 |
| QB-E010 | 属性値の不正 |
| QB-E011 | 退役済み ID の再利用(サーバ検証) |
| QB-E012 | リンク URL のスキームが許可リスト外 |
| QB-W001 | ID 未付与(保存時に自動付与) |
| QB-W002 | 外部画像の使用(許可設定時) |
| QB-W003 | 受験画面・結果画面に表示されない内容(`@text` の外の通常文など) |

## 11. AI に問題ブックを書かせるためのプロンプト

ChatGPT や Claude などに以下のプロンプトを貼り、`{...}` を自分の条件に置き換えて使います。
出力されたテキストをエディタに貼り付けて保存してください(設問 ID・空欄 ID は保存時に自動付与されます)。

````
あなたは「問題ブック記法(QB Markup)」で学習用の問題集を作る専門家です。
以下の記法と出力ルールに厳密に従い、指定された条件の問題ブックを 1 ファイル分のテキストとして出力してください。

# 出力ルール(厳守)
- QB Markup のソースだけを出力する。前置き・説明・コードフェンス(三連バッククォート)は書かない。
- 先頭に YAML フロントマターを置く。title は必須。title 以外は任意で、上のキー以外は書かない。
- 見出しは # / ## / ### を使う。本文には太字・リスト・表・数式($...$)・リンクを使ってよい。
- HTML は書かない。
- 設問 ID・空欄 ID は書かない(id=... や {qid=...} を出力しない)。保存時に自動付与される。
- 画像は、ユーザーがアセット名を指定した場合のみ ![説明](img:ファイル名){width=400} と書く。外部 URL は使わない。
- 問題は答えが一意に定まるように作る。
- 各設問に @explain で解説を付ける。必要なら @hint も付ける。
- 日本語で書く。専門用語には必要に応じて補足を付ける。

# 記法

## フロントマター(先頭に置く)
---
title: ブックのタイトル
description: 説明(任意)
tags: [tag1, tag2]
lang: ja
timeLimit: 600
practiceFeedback: true
shuffle: { questions: true, choices: true }
normalize: { kana: false }
---

## 設問ブロック
@q type=blank points=2
問題文。空欄は [[答え]] と書く。
@end

- type: blank(既定) / single / multi / truefalse / essay
- points: 配点。省略すると、その設問内の空欄の重み(w)の合計になる。
- 空欄の重み: [[答え]]{w=2}(既定は 1)
- 解説: @q の中に @explain 行を置き、その下に書く。ヒントは @hint。
- 記述式(essay)の模範解答は @model 行の下に書く。

@q type=single points=2
正しいものを 1 つ選べ。
- [x] 正解の選択肢
- [ ] 誤答の選択肢
@end
@explain
解説文。
@end

@q type=truefalse answer=false points=1
本文が正しければ正、誤りなら誤を選べ。
@end
@explain
解説文。
@end

## 空欄の書き方
[[答え]]                    完全一致
[[答え1 | 答え2]]           許容解答(どれか 1 つ)
[[/正規表現/]]              正規表現
[[=3.14 ±0.01]]             数値(許容誤差)
[[?正解 | 誤答A | 誤答B]]   選択肢空欄(先頭に ? を付けたものが正解)
- 表のセル内で | を使うときは \| と書く。

## 表示専用の文章
受験画面にも表示したい説明・資料は @text ... @end で囲む。
中の Markdown(太字・リスト・表・数式など)は解釈されるが、[[...]] は空欄にならず文字として表示される。
@text の中に @q は書かない。

@text
この文章は問題ではなく、受験画面にも表示される。
@end

# 作成条件
- テーマ: {テーマ}
- 対象: {対象}
- 問題数: {問題数} 問程度
- 難易度: {難易度}
- 出題形式: {出題形式}(例: 空欄中心、選択肢、記述)
- その他の要望: {要望}

# 出力例(この形式で、条件に合わせて内容を変えて出力する)
---
title: 江戸時代の基礎
description: 江戸幕府の成立と政治
tags: [history, japan]
lang: ja
practiceFeedback: true
---

@text
# 江戸時代

江戸時代は、1603 年に徳川家康が江戸幕府を開いてから、1867 年の大政奉還までの約 260 年間を指す。
@end

@q points=2
江戸幕府を開いた人物を答えよ。
[[徳川家康 | とくがわいえやす | 家康]]
@explain
1603 年に徳川家康が征夷大将軍に任じられ、江戸幕府を開いた。
@end

@q type=single points=2
江戸幕府が開かれた年は?
- [x] 1603 年
- [ ] 1600 年
- [ ] 1615 年
- [ ] 1867 年
@end
@explain
1600 年の関ヶ原の戦いの 3 年後、1603 年に江戸幕府が開かれた。
@end
````
